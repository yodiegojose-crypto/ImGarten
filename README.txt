# Jardinería Diego — MVP 0.2

Protótipo funcional com duas áreas:
- Cliente: serviços, orçamento, fotos, data, localização e confirmação.
- Jardineiro: painel, pedidos recentes, estatísticas, agenda, clientes, orçamentos e faturação.

Próximas etapas:

2. Login separado cliente/jardineiro
3. Notificações
4. Agenda sincronizada
5. Orçamentos e mensagens
6. Pagamentos
7. Publicação Android/iPhone
8. Versão marketplace para vários jardineiros
